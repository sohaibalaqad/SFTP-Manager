مدير ملفات SFTP — طريقة التشغيل
================================

لا تحتاج تثبيت أي شيء. أول تشغيل يحتاج إنترنت لتنزيل محرك التشغيل مرة واحدة فقط.

ماك (Mac)
---------
1. فك الضغط عن الملف ثم افتح المجلد.
2. انقر مرتين على:  Start SFTP Manager.command
   - أول مرة فقط قد يظهر تحذير "لا يمكن التحقق من المطوّر":
     انقر على الملف بالزر الأيمن ← فتح (Open) ← فتح (Open).
3. يفتح المتصفح تلقائيًا على البرنامج.
   للإيقاف: أغلق نافذة Terminal.

ويندوز (Windows)
----------------
1. فك الضغط عن الملف (Extract All) — لا تشغّله من داخل الملف المضغوط.
2. انقر مرتين على:  Start SFTP Manager (Windows).bat
   - إذا ظهرت رسالة "Windows protected your PC": اضغط More info ← Run anyway.
3. يفتح المتصفح تلقائيًا. للإيقاف: أغلق النافذة السوداء.

لينكس (Linux)
-------------
في مجلد البرنامج:  ./start.sh

ملاحظات
-------
- البرنامج يعمل على جهازك فقط (127.0.0.1) ولا يستطيع أحد غيرك على الشبكة فتحه.
- كلمات المرور لا تُحفظ. السيرفرات المحفوظة والبصمات تبقى في متصفحك فقط.
- إذا كان البرنامج يعمل مسبقًا، النقر على ملف التشغيل مرة أخرى يفتح المتصفح فقط.


SFTP File Manager — how to run
==============================
Nothing to install. The first run needs internet to download the engine once.

Mac:      double-click "Start SFTP Manager.command"
          (first time: right-click → Open → Open). To stop: close the Terminal window.
Windows:  extract the zip, then double-click "Start SFTP Manager (Windows).bat"
          (if SmartScreen appears: More info → Run anyway). To stop: close the window.
Linux:    ./start.sh

The app is only reachable from this computer (127.0.0.1).
