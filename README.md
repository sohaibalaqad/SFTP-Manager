# SFTP File Manager (Laravel)

واجهة ويب بسيطة بديلة لـ FileZilla: اتصل بسيرفر عبر **SFTP** وتصفّح الملفات وعدّلها وارفعها ونزّلها من المتصفح.

- بدون قاعدة بيانات، بدون تسجيل دخول، بدون مستخدمين.
- كلمة مرور SFTP **لا تُحفظ** بشكل دائم في أي مكان.
- Laravel 13 · phpseclib 3 (SFTP) · Alpine.js · Tailwind CSS 4 · CodeMirror 6 · واجهة عربية RTL مع الوضع الليلي.

## المتطلبات

- PHP 8.3+ مع الإضافات: `openssl`, `mbstring`, `fileinfo`, `ctype`, `tokenizer`
- Composer
- Node.js 20+ و npm (للبناء فقط)

لا حاجة إلى MySQL أو Redis أو migrations.

## التشغيل محليًا

```bash
composer install
cp .env.example .env
php artisan key:generate
npm install
npm run build
php artisan octane:install --server=frankenphp   # مرة واحدة: ينزّل FrankenPHP
```

### التشغيل (سريع — يبقي الاتصال بالسيرفر مفتوحًا مثل FileZilla)

```bash
php artisan octane:start --server=frankenphp --caddyfile=Caddyfile --host=127.0.0.1 --port=8010 --workers=4
```

ثم افتح `http://127.0.0.1:8010`.

- يبقى اتصال SFTP مفتوحًا بين الضغطات بدل فتح اتصال جديد في كل مرة، فتصبح العمليات أسرع بوضوح.
- يُغلق الاتصال المفتوح تلقائيًا بعد 5 دقائق بدون استخدام، أو فورًا عند "قطع الاتصال".
- `--workers=4`: عدد العمليات؛ كل عملية قد تحتفظ باتصال واحد لكل سيرفر (أي 4 اتصالات كحد أقصى).
- بعد تعديل كود PHP أعد تشغيل الأمر (أو أضف `--watch`).
- `--caddyfile=Caddyfile` ضروري: يجعل البرنامج يستمع على هذا الجهاز فقط (127.0.0.1). بدونه يستمع FrankenPHP على كل الشبكة حتى مع `--host=127.0.0.1`.

التشغيل القديم ما زال يعمل (أبطأ، يفتح اتصالًا جديدًا مع كل ضغطة):

```bash
php artisan serve --port=8010 --no-reload   # مع PHP_CLI_SERVER_WORKERS=4 في .env
```

## مشاركة البرنامج مع الأصدقاء (بدون تثبيت أي شيء)

```bash
npm run build
php artisan app:package
```

ينتج `SFTP-Manager.zip` (حوالي 10 MB). أرسله لصديقك؛ يفك الضغط وينقر مرتين على:
`Start SFTP Manager.command` (ماك) أو `Start SFTP Manager (Windows).bat` (ويندوز) أو `./start.sh` (لينكس).
أول تشغيل ينزّل FrankenPHP (يتضمن PHP) مرة واحدة ويتحقق من بصمته الرسمية (SHA-256)، ثم يفتح المتصفح.
الحزمة لا تحتوي `.env` أو مفاتيحك أو أي بيانات؛ كل جهاز ينشئ مفتاحه الخاص. التعليمات للأصدقاء في `README.txt` داخل الحزمة.
ويندوز يعمل بالوضع العادي (بدون إبقاء الاتصال مفتوحًا) لأن Octane لا يدعم FrankenPHP على ويندوز.

## النشر على VPS (Nginx + PHP-FPM)

```bash
cd /var/www/filemanager
composer install --no-dev --optimize-autoloader
cp .env.example .env        # ثم عدّل APP_URL
php artisan key:generate
npm install
npm run build
php artisan optimize
chown -R www-data:www-data storage bootstrap/cache
```

إعداد Nginx مقترح:

```nginx
server {
    listen 443 ssl http2;
    server_name files.example.com;
    root /var/www/filemanager/public;
    index index.php;

    # لا يوجد تسجيل دخول في التطبيق: قيّد الوصول (IP أو Basic Auth).
    # allow 203.0.113.10; deny all;
    # auth_basic "Restricted"; auth_basic_user_file /etc/nginx/.htpasswd;

    client_max_body_size 20M;   # أكبر من حجم جزء الرفع (chunk)

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";
    add_header Referrer-Policy "same-origin";

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include fastcgi_params;
        fastcgi_pass unix:/run/php/php8.3-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        fastcgi_buffering off;          # بث التنزيلات مباشرة
        fastcgi_read_timeout 3600;      # عمليات النسخ/الرفع الطويلة
    }

    location ~ /\.(?!well-known) { deny all; }
}
```

مع HTTPS اضبط في `.env`: `SESSION_SECURE_COOKIE=true`.

إعدادات PHP (php.ini) مقترحة للرفع:

```ini
upload_max_filesize = 16M
post_max_size = 20M
max_execution_time = 0   ; أو قيمة كبيرة
```

الرفع يتم على أجزاء (chunks) يُحسب حجمها تلقائيًا من هذه القيم، لذلك يمكن رفع ملفات أكبر بكثير من `upload_max_filesize`.

## طريقة الاستخدام

1. افتح الموقع وأدخل: اسم السيرفر، Host، Port، Username، Password، Remote Path.
2. اضغط **اتصال**. عند النجاح يُفتح مدير الملفات داخل Remote Path.
3. كل العمليات محصورة داخل Remote Path (لا يمكن الخروج منه بـ `..` أو عبر روابط رمزية).

### اختصارات لوحة المفاتيح

| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | نسخ / قص / لصق |
| `Delete` (أو `⌘+Backspace` على Mac) | حذف (مع تأكيد) |
| `F2` | إعادة تسمية |

| `Backspace` | رجوع |
| `Enter` | فتح |
| `↑` / `↓` | التنقل بين العناصر |
| `Ctrl+A` | تحديد الكل |
| `F5` | تحديث |

## مراقبة مجلد (تنبيه عند وصول ملفات جديدة)

زر **مراقبة** في شريط الأدوات ← "مراقبة هذا المجلد". يفحص البرنامج المجلد تلقائيًا (كل 15 ث / 30 ث / دقيقة / 5 دقائق)
ويحدّث القائمة بدون ضغط "تحديث"، وعند وصول ملف جديد:
- رسالة داخل البرنامج، وإشعار على سطح المكتب إذا كنت في برنامج آخر (فعّله من نفس القائمة)، وصوت تنبيه قصير.
- عدد الملفات الجديدة في عنوان التبويب، مثل **(3)**.
- علامة **جديد** على كل ملف جديد (تختفي عند النقر عليه)، و**قيد الوصول** إذا كان حجمه ما زال يتغير (لم يكتمل رفعه).
- تستمر المراقبة وأنت في مجلدات أخرى، ويتذكرها البرنامج في المرة القادمة لنفس السيرفر.
- الملفات المؤقتة لبرامج الرفع (`.part`, `.filepart`, `.crdownload`, `.tmp`) لا تُعتبر ملفات جديدة.
- ملاحظة: المتصفح يبطئ المؤقتات في التبويبات المخفية، فقد يصل التنبيه متأخرًا حتى دقيقة إذا كان التبويب في الخلفية.

## التبديل السريع بين السيرفرات

اضغط على اسم السيرفر أعلى مدير الملفات: تظهر السيرفرات المحفوظة. اختر واحدًا، أدخل كلمة المرور (أو المفتاح)،
فيُغلق الاتصال الحالي ويُفتح الجديد دون الرجوع لصفحة الاتصال. "اتصال بسيرفر جديد…" يفتح نموذجًا فارغًا.

## المقارنة والمزامنة (مجلد محلي ← مجلد على السيرفر)

1. افتح المجلد المحلي في لوحة "الملفات المحلية"، وافتح المجلد المقابل على السيرفر.
2. اضغط **مقارنة** في اللوحة المحلية. يُفحص المجلدان بكل مجلداتهما الفرعية ويظهر كل ملف بحالته:
   **جديد** (على جهازك فقط) · **معدّل** (نسختك أحدث) · **السيرفر أحدث** · **على السيرفر فقط** · **متطابق**.
3. "جديد" و"معدّل" محددان تلقائيًا؛ "السيرفر أحدث" غير محدد حتى لا تستبدل تعديلات أحدث بالخطأ.
4. **رفع المحدد** يرفع الملفات (ويُنشئ المجلدات الناقصة) مع شريط التقدم المعتاد. **لا يُحذف أي شيء من السيرفر.**

- طريقة المقارنة:
  - حجم مختلف ← **معدّل** مباشرة.
  - نفس الحجم ونفس التاريخ ← **متطابق**.
  - نفس الحجم وتاريخ مختلف ← تُقارن **بصمة المحتوى (SHA-256)** للنسختين (حتى 50 MB)، فيظهر ✓ محتوى.
    الملف المحفوظ دون تغيير لا يظهر كمعدّل، والتعديل على السيرفر بنفس الحجم يُكتشف.
  - لحساب بصمة نسخة السيرفر يُقرأ الملف مرة واحدة عبر SFTP (لا توجد أوامر على السيرفر). لا تُحفظ أي بصمات.
- خانة **تجاهل** تستثني أسماء مثل `.git, node_modules, *.log` (تُحفظ في المتصفح).
- لتسريع الفحص عبر الإنترنت، لا يُفتح على السيرفر إلا المجلدات الموجودة محليًا أيضًا.

## مالك الملف

- عمود **المالك** في قائمة الملفات (يظهر عندما تكون اللوحة عريضة بما يكفي، ويمكن الترتيب حسبه)،
  و**المالك والمجموعة** في نافذة **خصائص** (مثل `deploy (UID 1234)` و `webteam (GID 100)`).
- SFTP يعطي أرقام المالك/المجموعة فقط؛ الأسماء تُستخرج بقراءة `/etc/passwd` و `/etc/group` عبر SFTP
  (بدون أي أوامر Shell، وتُستخدم للأسماء فقط ولا يُعرض محتواها). تُحفظ في الجلسة 10 دقائق.
- في الحسابات المقيّدة (chroot) أو إذا لم تكن الملفات مقروءة، تظهر الأرقام (UID/GID) بدل الأسماء.

## تسجيل الدخول بمفتاح SSH

- في صفحة الاتصال اختر **مفتاح SSH** ثم **اختيار ملف المفتاح** (أو الصقه نصيًا)، وأدخل كلمة سر المفتاح إن وُجدت.
- الصيغ المدعومة: OpenSSH (`id_ed25519`, `id_rsa`…)، PEM، و PuTTY (`.ppk`).
- يُعامَل المفتاح مثل كلمة المرور تمامًا: يُشفَّر في الجلسة فقط (بمفتاح منفصل في cookie)، لا يُحفظ في أي ملف أو في المتصفح،
  ويُحذف عند قطع الاتصال. السيرفرات المحفوظة تتذكر فقط أن طريقة الدخول "مفتاح".

## التحقق من بصمة السيرفر (Host key)

- عند **أول اتصال** بسيرفر تظهر بصمة مفتاحه (مثل `SHA256:…`) لتتحقق منها قبل إرسال كلمة المرور أو المفتاح.
  للتحقق على السيرفر:

```bash
for f in /etc/ssh/ssh_host_*_key.pub; do ssh-keygen -lf "$f"; done
```

- بعد الموافقة تُحفظ البصمة في المتصفح (`localStorage` → `sftp.knownHosts`؛ معلومات عامة وليست سرًا).
- إذا **تغيّرت** البصمة لاحقًا يظهر تحذير أمني ويتوقف الاتصال **قبل** إرسال أي كلمة مرور أو مفتاح؛
  ولا يمكن الوثوق بالبصمة الجديدة إلا بعد تأكيد صريح.
- قائمة **البصمات الموثوقة** في صفحة الاتصال تتيح حذف بصمة (مثلًا بعد إعادة تثبيت السيرفر).
- البصمات مرتبطة بالمتصفح: متصفح أو جهاز جديد سيطلب التحقق مرة أخرى.

## استئناف الرفع المنقطع

- إذا انقطع الاتصال أثناء الرفع يعيد المحاولة تلقائيًا (حتى 8 مرات خلال ~2.5 دقيقة، وينتظر عودة الإنترنت دون استهلاك المحاولات)،
  ويكمل **من آخر بايت وصل للسيرفر** وليس من البداية.
- إذا استمر الانقطاع يتحول إلى **متوقف مؤقتًا** مع زر **استئناف**.
- حتى بعد إغلاق المتصفح: عند فتح الموقع مجددًا يظهر الرفع المتوقف؛ اختر **نفس الملف** (نفس الاسم والحجم وتاريخ التعديل)
  أو اسحبه مجددًا إلى نفس المجلد فيكمل من حيث توقف. تُتذكر هذه المعلومات أسبوعًا (أسماء وأحجام فقط).
- الجزء المرفوع يبقى على السيرفر كملف مخفي `.<الاسم>.<id>.part` ويُعاد تسميته عند الاكتمال. إذا لم تعد تريد إكماله اضغط ✕
  على الرفع المتوقف ليُحذف الجزء.

## سجل النقل والإشعارات

- زر **سجل النقل** أعلى مدير الملفات يعرض كل عمليات هذه الجلسة:
  - **رفع** (الجهاز ← السيرفر)، **تنزيل** (السيرفر ← الجهاز)، **حفظ من المحرر**.
  - لكل عملية: **من ← إلى** (مثال: جهازك `photos/a.jpg` ← السيرفر `/var/www/photos/a.jpg`)،
    الحالة (نجح / فشل / ملغى / جارٍ)، الحجم، المدة، الوقت، وسبب الفشل.
  - ملاحظة: المتصفح لا يكشف المسار الكامل على جهازك؛ يظهر اسم الملف (أو مساره داخل المجلد المسحوب)،
    وفي التنزيل يظهر "مجلد التنزيلات" الخاص بالمتصفح.
  - يمكن **تصديره** كملف نصي أو **مسحه**.
- السجل **مؤقت**: ملف JSON-lines في `storage/app/transfer-logs/` (صلاحيات 600) مرتبط بجلسة الاتصال،
  يُحذف عند "قطع الاتصال"، وتُحذف سجلات الجلسات المنتهية تلقائيًا عند أي اتصال جديد. لا يحتوي أي كلمات مرور.
- التنزيل يُعتبر ناجحًا فقط عندما يرسل الخادم كامل حجم الملف؛ إذا ألغى المستخدم التنزيل يُسجَّل "ملغى".
- **الإشعارات:** رسالة داخل الصفحة عند نجاح أو فشل كل رفع/تنزيل/حفظ، وشارة حمراء بعدد حالات الفشل على زر السجل.
  ويمكن تفعيل **إشعارات سطح المكتب** من لوحة السجل لتظهر عندما تكون الصفحة في الخلفية (تتطلب HTTPS أو localhost).

## اللوحة المحلية (مثل FileZilla)

- زر **الملفات المحلية** يعرض لوحة جانبية لملفات جهازك: اختر مجلدًا، تنقّل داخله، ثم اسحب الملفات/المجلدات إلى السيرفر
  (أو انقر مرتين على ملف لرفعه، أو زر **رفع →**).
- في **Chrome / Edge** (عبر HTTPS أو localhost) تستخدم اللوحة File System Access API:
  - يمكن أيضًا **سحب ملفات السيرفر إلى اللوحة** (أو "تنزيل إلى المجلد المحلي المفتوح" من القائمة) لتنزيلها داخل ذلك المجلد مباشرة، مع شريط تقدم حقيقي وإمكانية الإلغاء.
  - يتذكر المتصفح المجلد المختار (مرجع فقط في IndexedDB، دون محتوى)، ويطلب الإذن مجددًا عند الحاجة.
- في المتصفحات الأخرى تعرض اللوحة المجلد المختار **للقراءة فقط** (للرفع فقط).
- المتصفح لا يسمح بتصفح القرص كاملًا؛ تعرض اللوحة المجلد الذي تختاره أنت فقط.

## شريط التقدم

- لوحة **النقل** أسفل الصفحة تعرض كل رفع وتنزيل: من ← إلى، النسبة، الحجم، السرعة، الوقت المتبقي، والحالة، مع زر إلغاء.
- الرفع والتنزيل إلى المجلد المحلي: التقدم يُقاس في المتصفح مباشرة.
- التنزيل العادي (مجلد تنزيلات المتصفح): التقدم = ما أرسله الخادم فعليًا، يُحدَّث كل ثانية. إلغاؤه يتم من قائمة تنزيلات المتصفح.
- عند التطوير المحلي شغّل الخادم هكذا حتى يعمل تحديث التقدم أثناء التنزيل (خادم PHP المدمج يعالج طلبًا واحدًا فقط افتراضيًا):

```bash
PHP_CLI_SERVER_WORKERS=4 php artisan serve --no-reload
```

(على VPS مع PHP-FPM لا حاجة لذلك.)

## الرفع بالسحب والإفلات

- اسحب ملفات **أو مجلدات كاملة** من جهازك إلى قائمة الملفات لرفعها إلى المجلد الحالي؛
  تُنشأ المجلدات الفرعية تلقائيًا (بما فيها الفارغة).
- أفلتها **فوق صف مجلد** لرفعها داخل ذلك المجلد مباشرة (يتلوّن الصف بالأخضر) — حتى لو لم تكن لديك صلاحية فتح/عرض
  ذلك المجلد (مثل مجلد صلاحياته `-wx`)، تمامًا مثل FileZilla. في هذه الحالة لا يمكن فحص الأسماء المكررة مسبقًا،
  والسيرفر يرفض استبدال أي ملف موجود.
- اسحب عناصر من السيرفر إلى **مجلد آخر على السيرفر** لنقلها (مع تأكيد).
- إذا كانت أسماء موجودة مسبقًا يُسأل مرة واحدة: استبدال (مع الدمج داخل المجلدات) أو تخطي.
- الحد: 5000 ملف في الدفعة الواحدة.

## الحماية من الكتابة فوق تعديلات الآخرين

- عند فتح ملف في المحرر يُحفظ وقت تعديله وحجمه على السيرفر.
- عند العودة إلى نافذة المتصفح يُفحص الملف؛ إذا تغيّر (أو حُذف) يظهر شريط تحذير أعلى المحرر.
- عند الحفظ، إذا تغيّر الملف على السيرفر يظهر تحذير يعرض النسختين، مع ثلاثة خيارات:
  **استبدال بنسختي** / **تحميل نسخة السيرفر** / **إلغاء** (الافتراضي، حتى لا يستبدل Enter التعديلات بالخطأ).

## السيرفرات المحفوظة

تُحفظ في `localStorage` داخل المتصفح فقط، بالمفتاح `sftp.savedServers`، بالشكل:

```json
{ "name": "Production", "host": "server.example.com", "port": 22, "username": "root", "path": "/var/www" }
```

لا يوجد حقل `password` إطلاقًا. عند اختيار سيرفر محفوظ تُعبّأ الحقول وتبقى كلمة المرور فارغة.

## كيف تُعامَل كلمة المرور

- تُرسل مرة واحدة عند الضغط على "اتصال" (استخدم HTTPS).
- تُشفَّر بمفتاح عشوائي جديد لكل اتصال (AES-256-GCM):
  - النص المشفّر يُحفظ في الـ session (والـ session نفسها مشفّرة، `SESSION_ENCRYPT=true`، `SESSION_DRIVER=file`).
  - المفتاح يُحفظ في cookie مشفّرة من نوع `HttpOnly` و `SameSite=Strict` تنتهي بإغلاق المتصفح.
  - أيٌّ منهما وحده لا يكفي لاستعادة كلمة المرور.
- لا تُكتب في قاعدة بيانات (لا توجد)، ولا في `.env`، ولا في `localStorage`، ولا في السجلات (المعامل معلَّم بـ `#[\SensitiveParameter]`).
- لا تُعرض مرة أخرى في الواجهة.
- تُحذف عند "قطع الاتصال" (إبطال الـ session وحذف الـ cookie)، أو بعد 30 دقيقة خمول، أو بإغلاق المتصفح.

## القيود المعروفة

- لا يوجد تسجيل دخول: أي شخص يصل للموقع يمكنه استخدامه للاتصال بأي Host يستطيع خادمك الوصول إليه. قيّد الوصول عبر Nginx (IP / Basic Auth).
- PHP بلا حالة: يُعاد فتح اتصال SFTP في كل طلب (قد يضيف ~0.1–0.5 ثانية لكل عملية حسب السيرفر).
- النسخ Remote-to-Remote يمر عبر ملف مؤقت على خادم التطبيق (SFTP لا يدعم النسخ داخل السيرفر)، لكنه لا يمر عبر متصفح المستخدم. النقل (Cut/Paste) يتم بـ rename مباشرة على السيرفر.
- عند نسخ مجلد يتم تخطي الروابط الرمزية والملفات الخاصة بداخله.
- المحرر يفتح ملفات نصية UTF-8 حتى 5 MB؛ غير ذلك يُعرض كملف غير قابل للتعديل مع زر تنزيل.
- تنزيل المجلدات (ZIP) ورفع المجلدات غير مدعومين.
- البحث بالاسم فقط؛ البحث في المجلدات الفرعية محدود بـ 2000 مجلد و 300 نتيجة.
- نجاح التنزيل يعني أن الخادم أرسل الملف كاملًا؛ لا يمكن للمتصفح تأكيد أن الملف كُتب على القرص.
- سجل النقل يشمل الرفع والتنزيل والحفظ فقط (لا يشمل النسخ/النقل/الحذف داخل السيرفر؛ لها إشعارات مباشرة).
- الروابط الرمزية التي تشير لخارج Remote Path تظهر في القائمة لكن لا يمكن فتحها.
